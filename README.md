# TUTU 涂涂 · Simulation Demo v06

**[在线体验 Demo](https://luoqiying2023-a11y.github.io/TUTU-Simulation-demo/)** · [源码仓库](https://github.com/luoqiying2023-a11y/TUTU-Simulation-demo)

用于小红书测试题提交的移动端优先交互 Demo，基于 demo v06 整理。纯 HTML、CSS 与 JavaScript，无第三方运行依赖，无 API Key，无应用后端。

## 三份档案

- **模拟试用档案（推荐）**：完整固定故事，包含产品草稿、确认录入、预设白底图、搭配记录、试色图、推荐、实际使用反馈、保存与重置。
- **灵感演示档案**：四件示例产品与两套搭配，支持浏览和手动添加、编辑。
- **我的空白产品库**：空状态展示，支持手动录入产品、搭配和使用记录。

后两份档案不执行自动识别、推荐、转写或生成。模拟档案的语音文字、回复及图片均为预设素材；长按语音入口不会开启麦克风。试色为色调示意，不代表真实上脸效果。

## 推荐体验路径

1. 首次打开选择「模拟试用档案」。
2. 首页点击底部「＋」，选择 NARS Devilish不乖 产品图，完成选择。点击「未发送的想法」进入文字输入，或通过语音模拟输入「这是 NARS Devilish不乖 腮红，蜜瓜色，帮我记一下。」；核对草稿，确认录入。可查看模拟白底图并确认使用，也可稍后处理。
3. 在同一对话添加 Coral glow 与 Mauve Majesty 两张产品图，输入「我以前用这两件搭过，是Coral glow液体腮红和MOIRA粉紫色Mauve Majesty唇油，喜欢这组冷暖撞色，配深色衣服也好看」。核对搭配草稿，选择模拟试色、上传自己的试色或稍后补图，确认保存。
4. 返回首页开始新对话，输入「今天想用 MOIRA 这支粉紫色唇部产品，我记得它适合搭黑色衣服，腮红该怎么搭？」。查看已保存搭配，再点击「再想想」体验另一组模拟建议。
5. 选择「今天用这套」，随后输入「我回来啦，今天用了这套，挺喜欢的，配今天的黑色外套也好看。」；核对并保存实际使用反馈。
6. 浏览产品、搭配与对话记录；刷新页面检查保存。头像 →「我的档案」→「重新体验这份档案」可重置当前档案，另外两份档案不受影响。

## 本地预览

在此文件夹打开终端运行（需要 Python 3）：

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

访问 http://localhost:4174/ 。也可以运行 `npm start`，其作用相同。此命令仅提供静态文件，不运行 AI 或业务接口。不要双击 HTML：浏览器的 ES 模块需要通过 HTTP/HTTPS 加载。

## GitHub Pages 发布

把本目录内容上传到 `TUTU-Simulation-demo` 仓库根目录，确保 `index.html`、`app.js`、`assets/` 同级。

在仓库 Settings → Pages 中选择 Deploy from a branch，选上传代码的分支及 `/(root)`，保存。根目录 `.nojekyll` 应一并保留。在线入口：

https://luoqiying2023-a11y.github.io/TUTU-Simulation-demo/

已配置由 `main` 分支根目录发布。页面使用相对资源路径与 Hash 路由，适用于仓库子路径，无需配置路由重写。

## 数据与验证

数据与上传图片保存在当前浏览器的 IndexedDB；三份档案分别保存。更换设备、浏览器或域名不会自动同步，清除网站数据会删除记录。提交版使用独立数据库，不读取原 AI 版数据。

开发验证：安装 Node.js 后运行 `npm test`。提交版不包含百炼服务、环境配置、AI 适配模块或接口测试。
